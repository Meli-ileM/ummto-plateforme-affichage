## 🇬🇧 English

🗓️ *Developed Jan – Jun 2023 · published on GitHub in 2026*

### 💡 About
A communication platform for the Computer Science department of Mouloud Mammeri University of Tizi Ouzou: announcements, courses, grades, orientation requests and student appeals.
🎓 Bachelor's final project (Jan – Jun 2023). Role: full-stack developer.

### ✨ Features
- 👩‍🏫 Three spaces: administration, teachers, students
- 🔐 Authentication and account management (accounts created by the admin, password change)
- 📢 Publishing announcements, courses and grades
- 🧭 Orientation requests and student appeals, reviewed and confirmed by the administration
- 📋 Teacher and student lists management

### 🧩 Approach
Requirements analysis and user survey, UML modeling, UP (Unified Process) design, functional testing.

### 📂 Structure
```
src/        PHP application (htmlAdmin, htmlProf, htmlEtudiant, Commun…)
database/   Database schema (no data)
docs/       Project report and defense slides (French)
```

### 🚀 Getting started
1. Import `database/schema.sql` into MySQL (database `depinfo`).
2. Put `src/` in a local server folder (XAMPP, WAMP…).
3. Update the credentials in `src/database/database.php`.
4. Open `index.php`.

## 🇫🇷 Français

🗓️ *Développé de janv. à juin 2023 · publié sur GitHub en 2026*

### 💡 À propos
Plateforme de communication pour le département d'informatique de l'Université Mouloud Mammeri de Tizi Ouzou : annonces, cours, notes, demandes d'orientation et recours des étudiants.
🎓 Projet de Fin de Cycle, Licence Informatique (janv. – juin 2023). Rôle : développeuse full stack.

### ✨ Fonctionnalités
- 👩‍🏫 Trois espaces : administration, enseignants, étudiants
- 🔐 Authentification et gestion des comptes (création par l'administration, modification du mot de passe)
- 📢 Publication d'annonces, de cours et de notes
- 🧭 Demandes d'orientation et recours des étudiants, traités et confirmés par l'administration
- 📋 Gestion des listes d'enseignants et d'étudiants

### 🧩 Démarche
Analyse des besoins et sondage des utilisateurs, modélisation UML, conception selon la méthode UP, tests fonctionnels.
